# Exercise 1

I chose the following two exercises:

1. FizzBuzz
2. Linear Search

## FizzBuzz

The program iterates from 1 to 100. It prints:
- "Fizz" for multiples of 3
- "Buzz" for multiples of 5
- "FizzBuzz" for numbers that are multiples of both 3 and 5

## Linear Search

The linear search function goes through a list one item at a time and checks if each item matches the target value. If it finds the target, it returns the index. If not, it returns -1.

## Time Complexity

FizzBuzz has constant time complexity, O(1), because it always loops from 1 to 100.

Linear Search has linear time complexity, O(n), because in the worst case it may need to check every item in the list.
